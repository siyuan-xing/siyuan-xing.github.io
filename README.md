# Siyuan (Simon) Xing

Source code for [siyuan-xing.github.io](https://siyuan-xing.github.io), an academic website built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme.

## Local development

Install the Ruby dependencies listed in `Gemfile`, then run:

```sh
bundle exec jekyll serve
```

The site is deployed from `main` by `.github/workflows/deploy.yml`.
